# App Catalog List

## What is this?

This is the App Catalog list shown on the 2sxc.org [Apps page](https://2sxc.org/en/apps/). It's an Angular app that gets its data from the [App Catalog](https://github.com/2sxc-dev/2sxc.org-appcatalog) Razor app.

## Contributing

1. Clone the repo.
2. Work in the Angular folder [ng](/ng).
3. Start the Angular app, and use `local` to copy the files.
4. Open the live page and select `local`.
